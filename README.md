# ESP32 WiFi HTTP Template

A simple ESP32 WiFi and HTTP server template built using the **Arduino IDE**.

This project demonstrates how to:
- Connect an ESP32 to WiFi
- Create an HTTP server
- Create HTTP endpoints
- Receive POST requests
- Send HTTP responses

## Hardware

- ESP32 / ESP32-S3
- Arduino IDE
- Arduino ESP32 libraries

## Configuration

WiFi credentials and the server port are stored separately in `WiFi_Configs.h`.
